✦ Письма

Подключите нейросеть

Письма проверяет облачная модель Groq. Запросы отправляются напрямую из расширения. Сервер и его аренда не нужны.

  1. Откройте Groq Console → API Keys и создайте личный ключ.
  2. Для бесплатных проверок используйте план Free. Расширение не меняет тариф вашего аккаунта. Посмотреть квоты.
  3. Вставьте ключ ниже.

Загружаем настройки…

Ключ хранится только в этом профиле Chrome и не синхронизируется. Странице Gmail и её скриптам он не передаётся. Пользователь этого компьютера может получить доступ к ключу. Расширение не сохраняет тексты писем.

Модель: GPT-OSS 120B через Groq. После сохранения откройте Gmail и нажмите «Проверить письмо». Действуют квоты и правила Groq.
