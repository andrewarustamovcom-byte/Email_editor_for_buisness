# Данные и разрешения

Текущая версия напрямую отправляет выбранное письмо в **Groq**. Использование Алисы и собственного backend в этой сборке отсутствует. Это изменение согласовано владельцем: ключ разрешено хранить в браузере, модель можно заменить ради бесплатной API-квоты.

При нажатии «Проверить письмо» передаются тема и канонический текст выбранного черновика, явно отмеченные доступные сообщения или ручная история, язык, дата/timezone, технические id/revision/hash и категории. Скрытые письма, весь почтовый ящик, cookies и учётные данные Google не считываются. История изначально выключена, её можно просмотреть до отправки; при смене черновика выбор сбрасывается.

## Что сохраняет расширение

В chrome.storage.local находятся только **личный ключ Groq и числовые счётчики лимитов**. Они не синхронизируются и закрыты от content scripts через TRUSTED_CONTEXTS. Ключ читается worker и отправляется только в Authorization к фиксированному API Groq. Он не возвращается странице Gmail, не входит в ZIP и не записывается в код. Сохранение/удаление ключа доступны только собственной странице options.html.

Ключ доступен владельцу профиля/компьютера. Его локальное хранение не означает защиту от человека с доступом к профилю Chrome. Это принятое владельцем условие личной версии.

Письма, история, результаты и стек отмены хранятся только в памяти вкладки. Обновление страницы их очищает. В localStorage, chrome.storage и файлы они не записываются. Почта сохраняет собственные черновики по своим правилам.

## Groq

Используется синхронный Chat Completions без batch, fine-tuning, загрузки файлов, web search и других инструментов. По [политике Groq](https://console.groq.com/docs/your-data), служебные метаданные сохраняются; входы/выходы могут временно сохраняться для диагностики/расследования злоупотреблений. У провайдера есть Data Controls. Поэтому расширение не обещает полного отсутствия хранения у Groq.

## Разрешения Chrome

| Разрешение | Причина |
| --- | --- |
| Content script `https://mail.google.com/*` | Выбранный черновик, подсветка и подтверждённая точечная правка |
| Host `https://api.groq.com/*` | Прямой HTTPS-запрос из worker |
| storage | Личный ключ и постоянные счётчики |
| Action | Открыть панель на странице Gmail |

Нет all_urls, identity, cookies, пользовательской авторизации, доступа к почтовому API, удалённого исполняемого кода и host-доступа к localhost или собственному серверу. Код и промпт входят в ZIP. Clipboard используется только по кнопке копирования; при отказе текст можно скопировать вручную.

Локальные счётчики ограничивают попытки этого профиля и не являются глобальным лимитом провайдера. Для бесплатности используйте Groq Free; ключ платного аккаунта может вести к тарификации. Расширение не переключает план, не обходит квоты и не использует платного резервного провайдера.
