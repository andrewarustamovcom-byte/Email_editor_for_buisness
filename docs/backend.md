# Настройка backend владельцем

> Это документация ранее подготовленного, необязательного серверного варианта. По последнему решению владельца текущее расширение работает напрямую с Groq и не обращается к этому backend. Для него не нужны ВМ, домен, folder ID или ключ Яндекса. См. актуальный [README](../README.md). Для серверного варианта пример окружения сохранён в `deploy/backend.env.example`, live smoke — `npm run smoke:yandex`.

## Yandex AI Studio

Официальная документация проверена 15 октября 2026 года:

- [Синхронный native Text Generation API](https://aistudio.yandex.ru/ru/docs/ai-studio/text-generation/api-ref/TextGeneration/completion).
- [Модели и URI](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models).
- [Аутентификация](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/get-api-key).
- [Квоты и лимиты](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/limits).
- [Отключение логирования](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/disable-logging) и [политика хранения данных](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/security/data-storage).

Создайте облако/каталог с активным биллингом и сервисный аккаунт с минимальным доступом к генерации (роль `ai.languageModels.user` для выбранного каталога). Выпустите API-ключ с необходимой областью доступа. Сохраните его **только в `.env` сервера или серверном хранилище секретов**. Не коммитьте `.env`, не передавайте ключ в чат, в переменные `EXTENSION_*` или в параметры сборки расширения.

```dotenv
AI_PROVIDER=yandex
YANDEX_API_KEY=значение_только_на_сервере
YANDEX_FOLDER_ID=идентификатор_каталога
YANDEX_MODEL=aliceai-llm
YANDEX_API_BASE_URL=https://ai.api.cloud.yandex.net
```

YandexProvider использует `POST /foundationModels/v1/completion`, заголовок `Authorization: Api-Key …`, modelUri `gpt://<folder>/aliceai-llm`, jsonSchema, температуру 0.1, maxTokens и отключённые рассуждения. Это **native API**, не предположение об OpenAI-совместимости. `aliceai-llm-flash` не подходит для этого адаптера: документация указывает для неё OpenAI-совместимый API. Формат envelope `result.alternatives[].message.text` проверяется кодом; неполный, отфильтрованный или неверный ответ не становится правками. Владелец должен выполнить настоящий smoke-тест для выбранной модели и доступного каталога.

`npm run smoke:yandex` отправляет один обезличенный пример в уже запущенный YandexProvider backend и проверяет схему ответа. Это платный запрос в пределах общего бюджета. MockProvider никогда не проходит live smoke. Без доступов тест фактического подключения не выполнялся.

## Ограничение анонимного API

Пользовательской авторизации нет. CORS, Origin, UUID запроса и идентификатор расширения не служат защитой от посторонних вызовов. В расширении нет общего секрета. Произвольный клиент может обратиться к API и израсходовать выделенную квоту, поэтому сервер ограничивает последствия:

| Ограничение | Значение по умолчанию |
| --- | --- |
| HTTP body | 128 000 байт |
| Черновик / тема | 20 000 / 1 000 UTF-16 единиц |
| История | до 10 сообщений, 12 000 каждое, 24 000 суммарно |
| Ответ модели | до 128 000 байт и 20 замечаний |
| Выход модели | 3 000 токенов, жёсткий максимум конфигурации 6 000 |
| На IP / весь сервер | 6 / 20 запросов в минуту |
| Параллельные вызовы | 2 |
| Дневной / общий бюджет | 200 000 / 2 000 000 зарезервированных токенов |
| Запросов анализа в сутки | 100 |
| Полный вызов модели вместе с повтором | 25 секунд |

Значения меняются владельцем в окружении, не пользователем. До **каждой** внешней попытки на постоянный диск записывается консервативный резерв: UTF-8 байты всего payload, включая промпт/схему, плюс максимум выхода и запас. Неиспользованный резерв не возвращается — при сетевом сбое стоимость неизвестна. 429/502/503 допускают один повтор в пределах общего таймаута, с отдельным резервом. 401/403, сетевые ошибки, таймауты и некорректный JSON не повторяются.

Это ограничение токенов, а не точный денежный счётчик. Денежный потолок зависит от тарифа модели. Владелец выбирает небольшой бюджет по актуальной цене и настраивает облачные уведомления. Уведомление биллинга само по себе не считается жёсткой блокировкой. Достигнутый lifetime-предел блокирует новые внешние вызовы до осознанного изменения владельцем.

Счётчик `BUDGET_PATH` содержит только числа и день UTC, без текстов писем, IP и идентификаторов запросов. Дневной бюджет сбрасывается по UTC; lifetime никогда не сбрасывается автоматически. Требуются **один процесс и один постоянный том**; несколько реплик с независимыми счётчиками не допускаются. Эксклюзивный `.lock` не позволяет второму процессу использовать тот же файл. При повреждении ledger или ошибке записи вызов модели не выполняется. При аварийном завершении может остаться lock: остановите все экземпляры, проверьте ledger, удалите **только `.lock`**, запустите сервер. Не удаляйте budget.json при обновлении и не выполняйте `docker compose down -v`.

IP-лимитер не доверяет X-Forwarded-For. В поставляемой схеме Caddy все обращения имеют IP прокси и делят один IP-лимит; для личного использования это допустимое консервативное ограничение. Глобальная квота и lifetime-бюджет действуют независимо от IP. Не включайте `trustProxy: true` без закрытого upstream и точной настройки доверенного прокси.

## Вариант размещения: один Linux-сервер с Docker

Среда не была предоставлена; подготовлен переносимый вариант VPS + Docker Compose + Caddy HTTPS. Аренда сервера и регистрация домена выполняются владельцем. Нужны DNS A/AAAA на сервер, открытые 80/443, Docker с Compose. Порт API наружу не публикуется.

```bash
git clone https://github.com/andrewarustamovcom-byte/Email_editor_for_buisness /opt/pisma
cd /opt/pisma
cp deploy/backend.env.example deploy/.env
# Отредактировать deploy/.env на сервере: AI_PROVIDER=yandex, YANDEX_*;
# добавить BACKEND_DOMAIN=свой-домен, настроить лимиты.
docker compose --env-file deploy/.env -p pisma -f deploy/compose.yaml up -d --build
```

Для private-репозитория сначала настройте доступ Git. Ключ Yandex остаётся в `deploy/.env` на сервере. Caddy получает сертификат автоматически. Проверьте `https://свой-домен/health`, затем `npm run smoke:yandex` с `EXTENSION_API_URL` этого сервера. В production MockProvider запрещён конфигурацией. Обновление не должно удалять постоянный том budget. После аварии восстановите lock по инструкции выше.

Deployment в этой сессии не выполнялся. Владелец предоставил ID каталога и сообщил о создании ключа; домен, сервер и секрет в окружении backend не настроены. Это внешние шаги перед сборкой пользовательского релиза.
