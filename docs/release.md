# Выпуск прямого расширения

Текущая сборка предназначена для прямого Groq API и не требует серверного deployment. Первичная настройка — сохранение личного ключа в options.html. Ключ не встраивается в ZIP и не нужен GitHub Actions.

`ci.yml` запускает npm ci по lockfile, lint, TypeScript, unit-тесты, production build, Chromium E2E и сохраняет готовый ZIP как artifact. Облачных ключей и настоящих писем в CI нет.

`release.yml` срабатывает на vX.Y.Z, выставляет версию manifest из тега, повторяет проверки и публикует `pisma-X.Y.Z.zip` в GitHub Releases. EXTENSION_API_URL, домен, health endpoint, секреты Яндекса и платёжный аккаунт для выпуска больше не нужны.

```bash
npm ci
npm run build:release
```

Результат: `artifacts/pisma-0.1.0.zip`. Для будущей публикации после проверки владельцем:

```bash
git tag v0.1.0
git push origin v0.1.0
```

В текущей сессии push, тег и GitHub Release не создавались. Распространение первой версии: ZIP → распаковка → chrome://extensions → Режим разработчика → Загрузить распакованное расширение. Корпоративные политики не требуются.

Ранее подготовленный deploy.yml относится к необязательному backend в apps/api и для текущей версии не используется. Пользователь не должен разворачивать его для работы расширения.
