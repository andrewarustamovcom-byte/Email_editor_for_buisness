# Письма

Личное Chrome-расширение для проверки черновиков в **Gmail — https://mail.google.com/**. Сценарий: **«Проверить письмо» → замечания → «было / стало» → «Принять» / «Отклонить» / «Отменить»**.

По обновлённому решению владельца расширение обращается **напрямую в Groq**, модель `openai/gpt-oss-120b`. Сервер, аренда ВМ, домен и локальный backend не нужны. Алиса заменена облачной моделью с бесплатной API-квотой. В расширении нет регистрации, входа, SSO и почтового OAuth. **Личный ключ Groq один раз сохраняется в настройках расширения в вашем профиле Chrome.**

Бесплатность действует в пределах плана **Groq Free** и его квот. Расширение не переключает тариф, не покупает подписку и не обходит ограничения. Применение ключа платного аккаунта может тарифицироваться провайдером. Актуальные [условия Free](https://console.groq.com/docs/billing-faqs) и [лимиты](https://console.groq.com/docs/rate-limits) определяются Groq.

**Статус проверки:** код, схемы, безопасные правки и прямой сетевой сценарий проверяются автоматически с mock-ответами. Настоящий ключ Groq ещё не настроен; фактическое подключение и качество анализа нужно проверить после его ввода. Авторизованный Gmail не проверялся, тесты используют обезличенный DOM.

## Установка без сервера

1. Скачать готовый ZIP из GitHub Releases и распаковать в постоянную папку. При локальной сборке файл называется `artifacts/pisma-0.1.0.zip`.
2. Открыть `chrome://extensions`, включить **Режим разработчика**.
3. Нажать **Загрузить распакованное расширение**, выбрать папку с `manifest.json`.
4. При установке откроется страница подключения. Создать личный ключ в [Groq Console → API Keys](https://console.groq.com/keys), используя план **Free**, и сохранить ключ в этой странице расширения.
5. Открыть или обновить Gmail, открыть черновик, нажать значок расширения или плавающую кнопку **Проверить письмо**.
6. При нескольких черновиках выбрать нужный. По желанию включить историю, отметить доступные сообщения или вставить её вручную. До отправки видно, что войдёт в запрос.
7. Рассмотреть замечания. Каждую правку можно принять или отклонить; принятые правки отменяются в обратном порядке. Изменение черновика делает результаты устаревшими.

Настройки ключа доступны через **chrome://extensions → Письма → Сведения → Параметры расширения** и кнопку в панели. Ключ можно заменить или удалить. Он не входит в ZIP, GitHub и сообщения страницы Gmail. Серверные адреса, folder ID Яндекса, Node.js и терминал пользователю не нужны. Расширение не отправляет письмо автоматически.

Для обновления распакуйте новый ZIP в ту же папку, нажмите «Обновить» на `chrome://extensions` и обновите Gmail. В том же профиле сохранённый ключ и счётчики остаются.

## Сборка и проверки для разработчика

Нужны **Node.js 24.x**, npm и Chrome. Команды подходят для PowerShell Windows, Linux и macOS:

```powershell
npm ci
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Результат — `artifacts/pisma-0.1.0.zip`, с готовыми JS, manifest и страницей настройки. `npm run build:release` создаёт такой же пакет; `RELEASE_VERSION=vX.Y.Z` задаёт версию. URL сервера и ключ при сборке не нужны. Старый development ZIP с localhost больше не создаётся.

Linux CI устанавливает библиотеки Chromium: `npx playwright install --with-deps chromium`. Для просмотра обезличенного стенда: `npm run dev:fixture`, затем `http://127.0.0.1:5173/tests/fixtures/gmail.html`.

Настоящий smoke по требованию владельца: скопировать `.env.example` в `.env` (`Copy-Item .env.example .env` в PowerShell или `cp .env.example .env`), указать `GROQ_API_KEY` в файле и выполнить `npm run smoke:live`. Команда делает **один** запрос к Groq на обезличенном тексте, проверяет схему и цитаты, не печатает ключ или текст. Она не запускается в CI и не использует ключ, ранее опубликованный в чате.

## Ограничения

По умолчанию: одна попытка в минуту, до 30 в день, консервативный дневной резерв 200 000 токенов и общий резерв 2 000 000. Счётчики сохраняются до запроса и переживают перезапуск worker/браузера. Автоматических повторов, платного резервного провайдера и переключения тарифа нет. Ошибка API и невалидный ответ не превращаются в правки.

Это локальные ограничения вашего профиля, не доказательство бесплатного тарифа и не глобальный счётчик аккаунта. Квоты Groq могут ограничить длинное письмо раньше. Расширение не обрезает текст и историю молча; при отказе предлагается уменьшить выбранный контекст или повторить позже.

## Компоненты

| Путь | Назначение |
| --- | --- |
| `apps/extension/src/direct` | Прямой Groq API, проверка ответа, постоянные локальные лимиты |
| `apps/extension/src/background` | MV3 worker, ключ и фиксированный промпт |
| `apps/extension/src/options` | Сохранение и удаление личного ключа |
| `apps/extension/src/ui`, `adapters`, `content` | Панель, Gmail DOM, сравнение, безопасные правки и отмена |
| `packages/contracts` | Zod, JSON Schema, проверка цитат |
| `packages/prompts/email-review.ru.md` | Версионируемый промпт 1.0.0, включается в worker |
| `tests`, `.github/workflows` | Unit/API, Chromium E2E, CI и выпуск ZIP |
